# 📝 React CRUD Todo Application

A responsive Todo application built using **React.js** that allows users to manage daily tasks with Create, Read, Update, and Delete (CRUD) operations.

## 🚀 Features

* ➕ **Add Tasks** – Create new tasks with a name and description.
* 📋 **View Tasks** – Display all tasks as individual cards.
* ✏️ **Edit Tasks** – Update existing task details.
* 🗑️ **Delete Tasks** – Remove tasks from the list.
* 🔄 **Update Status** – Change a task's completion status.
* 🔍 **Filter Tasks** – Filter tasks based on their status.
* 📱 **Responsive Design** – Adapt the layout to different screen sizes.
* 🧩 **Reusable Components** – Organize the application into separate React components.

## 🛠️ Technologies Used

## 🧠 Key Concepts Used

* **React Components** – Split the application into reusable UI components.
* **useState Hook** – Manage tasks and filter selections.
* **Props** – Pass data and functions between components.
* **CRUD Operations** – Create, read, update, and delete tasks.
* **Array Methods** – Use `map()` to update tasks and `filter()` to remove or filter tasks.
* **Spread Operator** – Copy existing task data when updating an item.
* **Event Handling** – Handle form submissions, button clicks, and status changes.
* **Conditional Rendering** – Display task information according to its state.
* **Responsive CSS** – Build a layout suitable for different screen sizes.
